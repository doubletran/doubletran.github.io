Web Server

Index means the system of naming and sorting data by keyword for easier retrieval purpose. This definition can be used in relevance to a main page, as a main page is the root page that link to multiple subpages through buttons, links, headers, pictures. Therefore, index.html become the default name for the main page or the entry page of websites

In both local browser and web server, there are general, response headers, and request headers. However, the web server needs to go through HTTPS protocol to retrieve the HTML document, thus, the response and the request contain all components of the HTTP response and request with status line and request and response header. On the other hand, the local computer's protocol is the protocol file which is used to read HTML from local computer, so the response contain only little information such as content-type, last modified. The request header from the local computer show provisional headers because the request wasn't sent over the network but was served from a local cache.

The favicon.ico file has a status 200 because it is successfully retrieved from oregonstate web server to display along with the title. The main.css and main.js have status code 404 because there are no main.css and main.js file created on the server

The URL is https://web.engr.oregonstate.edu/~trantr3/a1-trantr3/, which can be partitioned into different components. First, scheme is the protocol the web client use to request the source. In our URL, it is HTTPS protocol. Second, the server name is "web.engr.oregonstate.edu" that state the location to which the request should be sent to in order for the document to be hosted there. There are subdomain and host domain in the server name. Our subdomain, the subsection of the server, is web.engr while the host domain is oregonstate that can be mapped to the IP address to locate the oregonstate server. Our path to resources is /~trantr3/a1-trantr3/ that identify the location of the requested resource on the server. As a convention, the request is mapped to index.html document if there is no file or destination included after "/" at the end of the path.

Frontend Design

Front-end design is about optimizing user experience by creating the page's visual design, the graphical user interface, and any interactive scheme. Some factors that help optimize the frontend design are using a consistent and apprporiate color scheme that reflect the website's purpose, or using the icon to guide the users to the specific tasks, or implementing the menu for users to navigate.

Effective
The application needs to help users meet their goal by containing an adequate amount of elements for users to locate their goals and get accurate results.
Efficient
The application needs to minimize the steps taken to accomplish a task by considering response time and levels of depth when designing navigation schemes such as navigation bar, buttons,...for a website.
Easy to navigate
The application needs to be easy for both new users and old users to locate their goal, their destination, and remember those steps next time. For example, fixed navigation bar allows users to navigate to other contents from anywhere on the current page.
Error-free
The application needs to avoid any issues, and roadblocks that prevent users from accessing, locating, and accomplishing their tasks. For example, errors with links stop users from navigating to their goals; errors with displaying stop users from viewing information.
Engaging/Enjoyable
The application needs to fit users’ needs with the four above principles and possibly their styles. If users are able to accomplish their goals successfully and quickly and users like the overall design, they will come back next time.

Page layout tags are used to help the developer organize the content in a structural way with header, navigation, main, section,articles, … By simplifying or automating the process of sectioning the content or differentiating the header and the body every time the developer uses the element.

Anchors can be used as a navigation tool or text anchor. For navigation, a group of anchors usually act as a nav bar to navigate to the other pages inside a website/application using relative URLs, since the navigation destinations are relative to the current page. For text anchors, the anchor link is embedded inside a text of a paragraph to link to another resource (usually containing further detail about that text) outside or inside the website.

Optimizing images

Six major specifications are file name should include descriptive information about the image to help the search engine bots to find and categorize it easier into the related images so that users can search for it; file's size should be reduced as small as possible; dimensions of the image must match within the space in the web page; image should be saved with the correct and appropriate file format; image's resolution need to be rendered between 72 or 300+ pixels per inch; image need to be created with correct color mode - RGB for .PNG, JPG, .SVG and .WebP and Indexed for GIF. Images need to follow six major specifications to minimize the load time and optimize the user experience. These specifications also ensure that images comply within the standard so that every device can display these correctly.

JPG and WebP are appropriate for photo because they can compress the file's size while maintaining rectangular form for the image. Even though the compression is lossy, its ability to compress photos is useful to help speed up the load time online. GIF, PNG are SVG are appropriate for line art because they handle higher transparency for more complex art. The compression for these file formats are lossless in order to minimize the distortion to the art. They also allow images to have non-rectangular form and transparent background.

Cascading stylesheets

The main reasons to incorporate stylesheets are to improve usability, readability, legibility and adhere to brand requirements and theme. Stylesheets allow the designer to manipulate the overall look of the website e.g. by adding fonts, changing the margin, padding, implementing flex box as well as adding design wise details to each specific elements. Stylesheets allow the designer to add interactive scheme to the element to optimize the user experience, e.g. color change when users hover over the button.

The most common way to incorporate styles is to link one or more external files stylesheet CSS file in the index.html in order to provide styles that link to the single global stylesheet. Another way is to embed the style within the style tag in the HTML file. There are other methods used to set more specific style for specific elements. We can embed the style using HTML attribute and value inline within that element in an HTML file. We can also code the style with JavaScript template literals in a JavaScript function. In a regular JavaScript, we can manipulate the Document Object Model for an element to set specific style for that element.
